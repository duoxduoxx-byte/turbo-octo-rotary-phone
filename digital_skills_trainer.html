Блок 01 · Структура сайта

Основы HTML

HTML — язык разметки, который задаёт структуру веб-страницы: заголовки, абзацы, изображения, ссылки и другие элементы.

Главные теги
  • <h1> — главный заголовок.
  • <p> — абзац текста.
  • <a> — ссылка.
  • <img> — изображение.
  • <ul> и <li> — список.
  • <head> — служебная информация, <body> — содержимое страницы.
Пример HTML-документа 
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Моя страница</title>
</head>
<body>
  <h1>Привет!</h1>
  <p>Это мой первый сайт.</p>
</body>
</html>
Практика

Представь, что создаёшь страницу о себе. Напиши в поле заголовок и абзац, затем нажми «Проверить».

Основы CSS

CSS отвечает за оформление HTML-страницы: цвета, размеры, шрифты, отступы, расположение и адаптацию под экран.

Как устроено CSS-правило

селектор { свойство: значение; }

  • color — цвет текста.
  • background — фон.
  • font-size — размер шрифта.
  • margin — внешний отступ.
  • padding — внутренний отступ.
  • border — граница элемента.
Пример CSS
h1 {
  color: royalblue;
  font-size: 32px;
}
p {
  background: #eeeeee;
  padding: 12px;
}

Блок 03 · Презентации

Основы Microsoft PowerPoint

PowerPoint — программа для создания презентаций из слайдов. Она помогает понятно и наглядно представить информацию.

Основные инструменты
  • Новый слайд — добавляет страницу презентации.
  • Макет — задаёт расположение заголовка и содержимого.
  • Вставка — добавляет изображения, фигуры, таблицы и диаграммы.
  • Переходы — эффекты смены слайдов.
  • Анимация — эффекты появления и движения объектов.
  • Показ слайдов — запуск презентации для просмотра.
Правила хорошей презентации
  • Одна главная мысль на слайд.
  • Короткие и понятные фразы.
  • Достаточно крупный шрифт.
  • Контрастный текст и фон.
  • Изображения должны помогать объяснять тему.
Практика

Составь план мини-презентации из трёх слайдов. Заполни тему и краткое содержание каждого слайда.
